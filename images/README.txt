Put your image files in this folder.

Recommended files to add (see js/music-data.js for exact filenames used):

  home-bg.jpg        -> homepage full-screen background
  lofi.jpg           -> Lofi category image
  bhakti.jpg         -> Bhakti category image
  old-songs.jpg      -> Old Songs category image
  romantic.jpg       -> Romantic category image
  chill.jpg          -> Chill category image
  trending.jpg       -> Trending category image
  instrumental.jpg   -> Instrumental category image
  classical.jpg      -> Classical category image
  icon-192.png       -> small app icon (for "Install")
  icon-512.png       -> large app icon (for "Install")

If an image is missing, Mood Changer automatically shows a nice
gradient instead, so the site never looks broken while you're
still collecting images.

To change any image, just drop a new file in this folder with the
SAME filename referenced in js/music-data.js, or edit the "image"
path in js/music-data.js to point to your new filename.
